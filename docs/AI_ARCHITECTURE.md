# TRADE ACADEMY AI

Мобильное приложение сейчас использует offline mentor engine в ai/mentorEngine.ts. Он работает без интернета и отвечает по темам risk management, position sizing, market structure, RSI, EMA, strategy, psychology, candles, journaling и Forex basics.

Для настоящего генеративного AI безопасная архитектура: Android app -> HTTPS backend -> LLM provider -> response. Секретный API key нельзя помещать в APK.

Терминал остаётся учебной симуляцией и не должен выдавать симулированные цены за live market data или обещать прибыль.
